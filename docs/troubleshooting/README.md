## 横断的な学び

- **診断の見える化が転機**: シリアルログが使えない環境（`M5.begin()` は `Serial.begin()` を呼ばない）で、HTTP `/state` に内部状態（タッチ判定・FS の認識状況など）を載せたことが、表示・タッチ・FS 不整合すべての調査基盤になった。
- **代替経路を先に通す**: VOICEVOX が無くても `say` で音声経路を先に確認、本物のフレームが無くてもテスト画像でパイプラインを先に完成。ソースが揃った瞬間に一気通貫できる。
- **要件側を緩める選択肢**: ダブルタップの閾値チューニングで粘るより、シングルタップ化の方が確実だった。
