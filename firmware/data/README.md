# M5 画面フレーム素材（LittleFS）

ここに置いた画像を M5 が起動時に読み込み、顔として表示します。

## アニメーション用フレーム
`clawd0.png`, `clawd1.png`, `clawd2.png` … と連番で置くと、起動時に枚数を自動検出し、
**順番にアニメーション表示**します（150ms/コマ）。1枚も無ければコード描画のキャラにフォールバック。

- 推奨：**黒背景**、画面の顔エリア（約 320×200）に収まるサイズ。中央寄せで描画されます。
- フォーマット：PNG（`drawPng`）。JPGを使う場合は単発表情として `normal.jpg` 等も可。

## 書き込み
```
cd firmware && pio run -e core2 -t uploadfs
```
